# Créditos do tema `default`

## Texturas de terreno

Geradas com [DiceBear](https://www.dicebear.com) 10 (`@dicebear/core` + `@dicebear/styles`) por `bun run tiles`, a partir de `tiles.dicebear.json`. Todos os estilos usados são **CC0 1.0** (domínio público):

| Terreno    | Estilo DiceBear | Licença |
| ---------- | --------------- | ------- |
| chão       | loops           | CC0 1.0 |
| parede     | patchwork       | CC0 1.0 |
| bloco      | squircles       | CC0 1.0 |
| água rasa  | loops           | CC0 1.0 |
| água funda | waves           | CC0 1.0 |
| mato alto  | stripes         | CC0 1.0 |
| gelo       | glass           | CC0 1.0 |
| lama       | blobs           | CC0 1.0 |

CC0 não exige atribuição; este arquivo existe para deixar a origem clara.
